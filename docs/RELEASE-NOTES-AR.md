# ⚡ AY Zygisk V2 (2.0.0)

**المطور:** Eng. Ahmed Yasir  
**التصميم:** Black & Gold – شعار برق ذهبي  
**نوع الإصدار:** حزمة مستقلة للتحكم والتشخيص.

## المميزات الجديدة

- لوحة تحكم كاملة بالعربية والإنجليزية، تعمل مع مدير موديولات يدعم WebUI.
- فحص توافق الأدوات ومعلومات النظام، وحالة تثبيت محرّك Zygisk إن وُجد.
- V2 Doctor: تقرير فحص متطلبات Android ومدير الروت والمعمارية دون ادّعاء نجاح تحميل المحرك.
- Integrity Guard: تدقيق SHA-256 لعشرة ملفات AY أساسية.
- النسخ الاحتياطي واسترجاع الخيارات محليًا مع التحقق من القيم قبل الاسترجاع.
- تقارير محلية وتحذيرات تعارض المحركات المثبتة وسجل اختياري.

## التثبيت
افتح Magisk أو KernelSU أو APatch، ادخل Modules ثم Install from storage، اختر ملف ZIP وأعد التشغيل.

## تحذير فني مهم
هذا إصدار V2 **نهائي لجزء التحكم والتشخيص فقط**، وليس محرك Zygisk Native مستقلًا. لا يقوم بحقن Zygote ولا بتشغيل إضافات Zygisk بدون محرك قائم. لم يتم تجميع واختبار مكتبات Android على جهاز فعلي بعد. لا يضمن إخفاء الروت أو تجاوز فحوص التطبيقات الحساسة.
