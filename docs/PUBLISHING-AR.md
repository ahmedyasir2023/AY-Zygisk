# منشور AY Zygisk V2 — وصف صالح للنشر

**العنوان:** AY Zygisk V2 — Black & Gold Diagnostics Controller
**المطور:** Eng. Ahmed Yasir
**التصنيف:** Root Module Tools / Diagnostics
**مديرو الروت:** Magisk، KernelSU، APatch (ملف ZIP موحد)

⚡ مميزات AY Zygisk V2: واجهة تفاعلية عربية/إنجليزية سوداء وذهبية، تشخيص الموديولات، فحص المعمارية ELF، V2 Doctor، التحقق من سلامة الملفات، تقارير محلية، ومراقبة تغيّر قائمة الموديولات وفحص توافق برامج Zygisk.

**تنويه مهم:** إصدار V2 الحالي مستقل للتحكم والتشخيص، لكنه لا يُشغّل إضافات Zygisk بنفسه، ولا يضم محرّك حقن Zygote. لم تُجرَ اختبارات فعلية على هواتف Android عبر المدراء الثلاثة. لا يستبدل محرّك Zygisk Next. لا يدّعي إخفاء الروت أو تجاوز فحوص التطبيقات الحساسة.
